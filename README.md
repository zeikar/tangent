# tangent

An agent-driven studio for short-form math / science / engineering explainers:
code-rendered animation in the 3Blue1Brown vein, produced by a pipeline of
Claude Code agents with human checkpoints.

*A tangent: the line that just touches the curve, and the short detour off the
main topic.*

Status: milestone 1, producing the first short by hand, stage by stage. See
[docs/decisions.md](docs/decisions.md) and
[docs/milestone-1-notes.md](docs/milestone-1-notes.md).
