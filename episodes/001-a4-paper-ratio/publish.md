## Description
```
A4 용지는 210 × 297 mm예요. 왜 하필 이런 애매한 숫자일까요?
반으로 접어 보면 보여요. A4는 몇 번을 접어도 모양이 그대로거든요.
미국 레터 용지는 접으면 더 길쭉해지는데 말이에요.

짧은 변을 1, 긴 변을 x라고 하면
반으로 접어 세운 종이는 긴 변이 1, 짧은 변이 x/2예요.
모양이 같으려면 x : 1 = 1 : x/2
→ x × x/2 = 1 → x² = 2 → x = √2
반으로 접어도 모양이 그대로인 직사각형은 1 : √2 하나뿐이에요.

실제 A4는 297 ÷ 210 ≈ 1.41429로, √2 ≈ 1.41421과 거의 같아요.
그리고 국제 표준(ISO 216)에서 A0는 넓이가 1 m²가 되도록 정한 크기예요.
A0를 반씩 네 번 접으면 바로 A4가 돼요.
```
